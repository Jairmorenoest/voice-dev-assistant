# Software Journey - VoiceDev Assistant

## Introducción

Este sitio documenta el proceso de desarrollo del proyecto VoiceDev Assistant, una aplicación académica orientada a comprender la arquitectura de asistentes de voz en tiempo real mediante Python y asyncio.

La documentación se enfoca en la experiencia de co-creación entre desarrolladores humanos y herramientas de inteligencia artificial, aplicando conceptos de Ralph Loops, Claude Code y los principios expuestos en el libro *A Philosophy of Software Design* de John Ousterhout.

---

## Objetivo del Proyecto

El objetivo principal del proyecto fue construir un agente de voz conversacional mínimo que permitiera comprender el flujo interno de procesamiento de voz utilizado por sistemas modernos de inteligencia artificial.

El sistema sigue el siguiente flujo:

Micrófono → Speech-to-Text → LLM → Text-to-Speech → Altavoz

---

## Secciones de la Documentación

### 1. La Bala Trazadora y el Enrutamiento de las Skills

Describe la estrategia inicial de reducción de riesgo utilizada durante la construcción del sistema y cómo se validó tempranamente la arquitectura.

### 2. Anatomía de la Complejidad

Analiza la calidad del diseño del software mediante los conceptos de módulos profundos, módulos superficiales y fuga de información.

### 3. El Veredicto Retrospectivo de los Sub-Agentes

Presenta una evaluación retrospectiva de las decisiones arquitectónicas tomadas durante el desarrollo del proyecto.
